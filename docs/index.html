وب‌سایتت را بهتر ببین، هوشمندانه‌تر بهینه کن

افزونهٔ متن‌باز و رایگان کروم برای تحلیل SEO، محتوا و GEO — بدون ثبت‌نام.

دانلود فایل زیپ چطور نصب کنم؟

نسخه ۰٫۱٫۱ · Chrome Manifest V3

نصب در کروم

چهار قدم؛ کمتر از یک دقیقه.

  1. ۱

    دانلود و Extract

    فایل weblens-chrome.zip را بگیرید و از حالت فشرده خارج کنید.

  2. ۲

    صفحهٔ افزونه‌ها

    در کروم برو به chrome://extensions.

  3. ۳

    Developer mode

    حالت توسعه‌دهنده را در بالای صفحه روشن کن.

  4. ۴

    Load unpacked

    پوشه‌ای را انتخاب کن که داخلش فایل manifest.json باشد — نه خودِ فایل زیپ و نه پوشهٔ بالاتر.

چه می‌بینی

تحلیل روی دستگاه خودت؛ بدون ارسال خودکار صفحه به سرور.

  • SEO فنی عنوان، متا، هدینگ، تصویر، لینک، Schema
  • محتوا خوانایی، ساختار، نگارش فارسی
  • GEO آمادگی برای جست‌وجوی مبتنی بر هوش مصنوعی
  • AI اختیاری تحلیل اصلی بدون API کار می‌کند

ساخته‌شده با دقت برای وب فارسی

وب‌لنز را پویا عظیم‌زاده ساخته؛ توسعه‌دهنده‌ای که روی هوش مصنوعی، اتوماسیون و تجربهٔ دیجیتال کار می‌کند.

اگر خواستی مسیر کار، پروژه‌ها یا همکاری را ببینی، از گیت‌هاب و لینکدین سر بزن.
