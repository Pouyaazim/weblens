WebLens

وب‌سایتت را بهتر ببین، هوشمندانه‌تر بهینه کن

افزونهٔ متن‌باز و رایگان کروم برای تحلیل SEO، محتوا و GEO — بدون ثبت‌نام و بدون اشتراک.

دانلود فایل زیپ چطور نصب کنم؟

نسخه ۰٫۱٫۲ · Chrome Manifest V3

نصب در کروم

چهار قدم ساده؛ کمتر از یک دقیقه.

  1. ۱

    دانلود و Extract

    فایل weblens-chrome.zip را دانلود کنید و Extract کنید؛ پوشهٔ weblens ساخته می‌شود.

  2. ۲

    صفحهٔ افزونه‌ها

    در کروم به آدرس chrome://extensions بروید.

  3. ۳

    Developer mode

    حالت توسعه‌دهنده را در بالای صفحه روشن کنید.

  4. ۴

    Load unpacked

    همان پوشهٔ weblens را انتخاب کنید (داخلش باید manifest.json باشد) — نه خودِ فایل زیپ.

چه چیزی می‌بینی

تحلیل روی دستگاه خودت انجام می‌شود؛ صفحه به‌صورت خودکار به سرور فرستاده نمی‌شود.

  • SEO فنی عنوان، متا، هدینگ، تصویر، لینک و Schema
  • محتوا خوانایی، ساختار و نگارش فارسی
  • GEO آمادگی برای جست‌وجوی مبتنی بر هوش مصنوعی
  • AI اختیاری تحلیل اصلی بدون API کار می‌کند

ساخته‌شده با دقت برای وب فارسی

وب‌لنز را پویا عظیم‌زاده ساخته است؛ توسعه‌دهنده‌ای که روی هوش مصنوعی، اتوماسیون و تجربهٔ دیجیتال کار می‌کند.

برای دیدن پروژه‌ها و مسیر حرفه‌ای، گیت‌هاب و لینکدین را دنبال کنید.
