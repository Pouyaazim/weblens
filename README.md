# WebLens — وب‌لنز

> **وب‌سایتت را بهتر ببین، هوشمندانه‌تر بهینه کن.**
> Understand the web. Improve every page.

WebLens یک افزونه **متن‌باز و کاملاً رایگان** برای Google Chrome است که به شما امکان می‌دهد هر صفحه وب را از نظر فنی، ساختاری، محتوایی و آمادگی برای موتورهای جست‌وجوی مبتنی بر هوش مصنوعی (GEO) بررسی کنید.

مشکلات صفحه را شناسایی می‌کند، شواهد واقعی هر مشکل را نمایش می‌دهد، میزان اهمیت آن را مشخص می‌کند و پیشنهادهای عملی برای بهبود ارائه می‌دهد.

## ✨ ویژگی‌ها

- 🔍 **تحلیل Technical SEO** — عنوان، Meta Description، هدینگ‌ها، تصاویر، لینک‌ها، Schema، Open Graph و...
- 📝 **تحلیل کیفیت محتوا** — حجم و ساختار محتوا، خوانایی، تکرار، نگارش فارسی (نیم‌فاصله، ی/ک)
- 🤖 **تحلیل GEO** — آمادگی صفحه برای سیستم‌های جست‌وجوی مبتنی بر هوش مصنوعی
- 📊 **امتیازدهی قابل توضیح** — امتیاز کلی، فنی، محتوا، GEO و متادیتا بر اساس معیارهای مستند
- 💡 **پیشنهادهای عملی** — هر پیشنهاد با شواهد واقعی، شدت مشکل و اقدام مشخص
- 🧠 **دستیار هوشمند (اختیاری)** — اتصال به OpenRouter برای تولید Meta، FAQ، Schema و تحلیل عمیق
- 📋 **گزارش‌ها** — ذخیره محلی در IndexedDB، جست‌وجو، فیلتر، خروجی JSON و HTML، چاپ
- 🌙 **تم روشن و تیره** — رابط کاملاً فارسی و راست‌چین با فونت وزیرمتن

## 🆓 اصول محصول

- کاملاً رایگان — هیچ پلن پولی، اشتراک یا قابلیت Premium وجود ندارد
- بدون نیاز به ثبت‌نام و ساخت حساب
- تحلیل‌های فنی **بدون هوش مصنوعی** به‌طور کامل کار می‌کنند
- پردازش روی دستگاه کاربر انجام می‌شود؛ داده‌ای به سرور ارسال نمی‌شود
- هوش مصنوعی کاملاً اختیاری است و فقط با اقدام صریح کاربر فعال می‌شود

## 🚀 نصب

### نصب از روی سورس (توسعه)

```bash
git clone https://github.com/Pouyaazim/weblens.git
cd weblens
npm install
npm run build
```

سپس در Chrome:

1. به `chrome://extensions` بروید
2. حالت **Developer mode** را فعال کنید
3. روی **Load unpacked** کلیک و پوشه `.output/chrome-mv3` را انتخاب کنید

### اجرای محیط توسعه

```bash
npm run dev
```

## 🧠 تنظیم هوش مصنوعی (اختیاری)

1. در [OpenRouter](https://openrouter.ai) حساب بسازید و یک API Key بگیرید
2. در افزونه به بخش **تنظیمات** بروید
3. کلید API را وارد کنید، AI را فعال کنید و مدل را انتخاب کنید
4. روی **آزمایش اتصال** کلیک کنید

> کلید API فقط در فضای ذخیره‌سازی محلی مرورگر شما نگه داشته می‌شود و هرگز به سرویس دیگری ارسال نمی‌شود (به‌جز درخواست صریح به OpenRouter).
> محدودیت‌های سرویس OpenRouter (مثل سقف مصرف مدل‌های رایگان) مربوط به خود OpenRouter است، نه WebLens.

## 🔒 حریم خصوصی

- هیچ تاریخچه مرورگری جمع‌آوری نمی‌شود
- محتوای صفحات به‌صورت خودکار به هیچ سروری ارسال نمی‌شود
